## 🧠 What It Does

Figma-based design deliverable: two web page mockups for an online bookstore, "Shae's
Books" - a Welcome Page and a Category Page.

## 🎯 Why It Matters

Establishes a consistent design system (colors, spacing, component layout) that every
later stage - static HTML, then Vue, then the full application - implements against,
rather than improvising layout decisions mid-build.

---

## 🎬 Scenario

A local bookstore owner wants to expand their business online, allowing users to buy
physical books and access electronic formats.

---

## 🎨 Design Considerations

- Applied design principles from *The Non-Designer's Design Book* (contrast, repetition,
  alignment, proximity)
- Considered accessibility guidance from the "Designing for Accessibility" posters
- Unique design reflecting the bookstore's own identity, not a generic template
- Consistent header/footer across both pages
- Designed to remain readable/usable across a 1000px-1400px viewing width
- Real book cover images sourced from Alibris.com/Audible.com, rather than placeholders
- CSS-only animations/effects planned for later implementation, avoiding JavaScript where
  possible

## 📝 Notes
